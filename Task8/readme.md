Поставленные задачи:
1.	Компоновка:
•	Создайте окно с использованием контейнера Grid.
•	Разделите окно на три колонки и две строки.
•	В первой колонке разместите StackPanel с вертикальной ориентацией, содержащий три кнопки.
•	Во второй колонке разместите DockPanel, содержащий текстовое поле (TextBox) и кнопку, прикрепленную к нижней части панели.
•	В третьей колонке разместите WrapPanel, содержащий пять RadioButton. RadioButton должны быть объединены в группы по 3 и 2 кнопки.
•	В первой строке второй колонки разместите Canvas, на котором можно перемещать элемент Ellipse с помощью мыши.
2.	Элементы управления:
•	Добавьте элемент ComboBox в первую строку первой колонки, содержащий список из трех элементов.
•	Добавьте элемент ListBox во вторую строку третьей колонки, содержащий список из пяти элементов.
•	Добавьте элемент CheckBox в первую строку третьей колонки.
•	Добавьте элемент Slider во вторую строку второй колонки, который будет изменять размер шрифта в текстовом поле.
•	Добавьте элемент DatePicker в первую строку второй колонки.
•	Добавьте элемент ProgressBar во вторую строку первой колонки, который будет отображать прогресс выполнения задачи.
•	Добавьте элемент ToolTip к кнопокам, который будет отображать подсказку при наведении курсора.
•	Добавьте элемент GroupBox в первую строку третьей колонки, содержащий два элемента RadioButton.
•	Добавьте элемент Expander во вторую строку третьей колонки, содержащий текстовое поле.
3.	Интерактивность:
•	Реализуйте обработчики событий для кнопок, которые будут изменять содержимое текстового поля или других элементов управления.
•	Реализуйте обработчик события для Slider, который будет изменять размер шрифта в текстовом поле.
•	Реализуйте обработчик события для ComboBox, который будет изменять цвет фона окна в зависимости от выбранного элемента.
•	Реализуйте обработчик события для ListBox, который будет отображать выбранный элемент в текстовом поле.
•	Реализуйте обработчик события для CheckBox, который будет включать или отключать элемент ProgressBar.
•	Реализуйте обработчик события для DatePicker, который будет отображать выбранную дату в текстовом поле.
