Задачи:
Цель:
Ознакомиться с паттерном MVVM (Model-View-ViewModel) в WPF, реализовав простое приложение «Список задач». 
Описание:
Разработайте WPF-приложение для управления списком задач. Приложение должно включать три основных компонента:
	Model (Модель): Класс, представляющий задачу.
	ViewModel (Модель представления): Логика работы с задачами.
	View (Представление): Графический интерфейс пользователя.
Функциональные требования:
	Пользователь может добавлять новые задачи.
	Пользователь должен иметь возможность редактировать задачи.
	Пользователь может удалять задачи из списка.
	Пользователь должен иметь возможность отфильтровать задачи, отобразив только выполненные, только не выполненные и все задачи
	Пользователь должен иметь возможность сохранить и открыт список задач в файл/из файла (например, JSON или XML).
	Пользователь может отмечать задачи как выполненные.
	Интерфейс должен обновляться при изменении данных (использовать INotifyPropertyChanged).
	Должна использоваться команда (ICommand) для выполнения действий (например, добавление и удаление задач).
Технические требования:
	Использовать паттерн MVVM.
	Применить биндинги данных в XAML.
	Использовать ObservableCollection для хранения списка задач.
	Реализовать команды через RelayCommand или DelegateCommand.
	Соблюдать принципы чистой архитектуры (разделение логики и представления).
