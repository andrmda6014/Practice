Задача:
Разработать пользовательский контрол для реализации индикации. Контрол должен взаимодействовать с коллекцией изображений и в зависимости от параметра Value (int) выводить определенный элемент.
Требования:
1.	Контрол:
•	Должен любым способом принимать изображения в формате png при создании и изменении
•	Должен поддерживать сколько угодно состояний. Если значение Value больше количества заданных состояний, то контрол должен вывести изображение-заглушку с однозначной индикацией.
•	Размер контрола должен задаваться из xaml.
2.	Применение 1:
•	На окно приложения выведите пользовательский контрол с несколькими картинками, реализующими один сюжет (например нарезка картинок под gif).
•	На окно приложения выведите кнопку.
•	Пользователь нажимает на кнопку и изображение меняется. Если пролистывание изображений перешло к последнему элементу, то следующей картинкой должна быть первая в последовательности.
3.	Применение 2:
•	На окно приложения выведите пользовательский контрол с тремя состояниями вентилятора.
•	На окно приложения выведите строку ввода (должны вводиться только числа, стандартное значение 1000), кнопку «Применить» и кнопку «Старт/Стоп».
•	Пользователь вводит в строку ввода числовое значение частоты смены изображений в миллисекундах. При нажатии кнопки «Применить» настройка применяется. При нажатии «старт/стоп» начинает/заканчивает проигрываться анимация смены изображений.

Используемые библиотеки:
using System;

using System.Windows.Media.Imaging;
using System.Timers;
